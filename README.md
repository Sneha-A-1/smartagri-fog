# SmartAgri-Fog

**Intelligent Cloud-Enabled Framework for Smart Agriculture** — a research platform for designing, simulating,
comparing and evaluating cloud–fog–edge computing strategies for agriculture.

Developed as part of the PhD research *"Design and Development of an Efficient Cloud-Enabled Framework for Smart
Agriculture."*

> Status: early development (Phase 0 — foundations). Every feature in the platform carries an explicit status:
> **Implemented**, **Simulated**, **Needs integration** or **Planned**. Nothing simulated is presented as real.

Setup and run instructions are added with the Phase 0 code in `docs/getting-started.md`.
